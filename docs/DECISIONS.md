- **2026-05-29 · Symbols encoded as `0 = fire`, `1 = water`; edges as `{orientation:'h'|'v', r, c, kind:'eq'|'ne'}`.** *Why:* a compact, framework-agnostic representation the engine, design tokens (`SYMBOL`), and future Dart port can all share; matches the design handoff's data shape.
- **2026-05-29 · Engine solver is single-cell forced-move propagation (adjacency / balance / edge), uniqueness via independent backtracking.** *Why:* mirrors how a person reasons ("if this were fire we'd get three in a row, so it's water"), guarantees deduction-only with no guessing, and keeps uniqueness verification separate so it holds even for puzzles the human solver can't crack. Generator greedily removes givens while both checks pass; difficulty is scored from solver effort (empties + propagation passes + technique premiums), with easy/medium reached by revealing givens to a score setpoint. Validated by a 600-puzzle fuzz suite.
- **2026-05-29 · Tooling: pnpm workspaces, TypeScript strict (+`noUncheckedIndexedAccess`), Vitest for the engine.** *Why:* matches global TS conventions; Vitest is ESM-native and fast; `apps/web` (Next.js) + `supabase/` are stubbed now and built out in Phase 3 to keep this pass focused on tokens + engine.
- **2026-05-29 · Renamed to "Parity"; symbols changed from sun/moon to fire & water.** Supersedes the earlier "Lumen / refined-celestial" identity. *Why:* sun/moon is Tango's signature element and undercut the goal of an original stamp; and "Lumen" (a unit of light) only fit a celestial theme. *Now:* the name **Parity** is decoupled from the art (it names the balance rule), and the pieces are an amber-red **flame** vs cool teal **droplet** — genuine opposites mapping to the `≠` rule, with fire as the single hero accent. The earlier sun+moon master mark also failed the 44px squint test (muddy overlap); the new mark must read as one clean shape at small sizes. Folder + GitHub repo renamed `lumen` → `parity` (old URL auto-redirects).
